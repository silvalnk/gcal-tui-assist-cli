# Product

**GCal TUI** é uma agenda quieta, somente leitura, para o terminal. Busca uma vez, mostra, sai.

Inspiração: [google-calendar-tui](https://github.com/akitaonrails/google-calendar-tui) (Rust + GOA). Este fork conceitual é TypeScript e **ICS-first** porque o ambiente inclui WSL.

Valor central: ver os próximos compromissos sem OAuth app, sem daemon, sem UI web.

Não é um cliente completo do Google Calendar. Não escreve eventos. Não usa GNOME Online Accounts na v1.

GitHub: [silvalnk/gcal-tui-assist-cli](https://github.com/silvalnk/gcal-tui-assist-cli)
